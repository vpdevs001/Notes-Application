# 📝 Premium Notes Application

A beautifully designed, responsive notes application built with **React Native** and **Expo**. This app combines modern aesthetics with practical functionality, providing a seamless note-taking experience with dynamic visuals.

## ✨ Key Features

- **🌅 Dynamic Time-Based Backgrounds**: The application interface breathes and changes with your day. The background automatically updates to reflect the current time:
  - **Morning**: Soft, early light to start your day.
  - **Afternoon**: Bright and energetic visuals.
  - **Evening**: Warm, calming tones as the sun sets.
  - **Night**: Deep, dark aesthetics for late-night productivity.

- **🌗 Dual Theming System**:
  - **Smart Defaults**: Automatically detects and matches your system's Light or Dark mode.
  - **Manual Toggle**: Take control with a quick-access theme switch in the header.
  - **Consistent Aesthetics**: Every component is carefully styled for both light and dark environments.

- **📓 Effortless Note Management**:
  - **Create & Edit**: Add new ideas instantly or refine existing ones with a sleek modal interface.
  - **Clean Display**: Notes are presented in elegant cards with clear typography.

- **🔍 Smart Search**:
  - **Real-time Filtering**: Find exactly what you're looking for as you type.
  - **High Performance**: Optimized list rendering for a smooth searching experience.

- **💎 Premium UI/UX Design**:
  - **Modern Glassmorphism**: Utilizes translucent layers, blurred backgrounds, and subtle shadows for a high-end feel.
  - **Poppins Typography**: Integrated with Google Fonts for a clean, professional, and readable look across all devices.
  - **Smooth Animations**: Powered by `react-native-reanimated` for fluid transitions and interactions.
  - **Responsive Layout**: Fully optimized for various screen sizes with `SafeAreaView` support.

## 🛠️ Built With

- **Framework**: [React Native](https://reactnative.dev/)
- **Platform**: [Expo](https://expo.dev/) (SDK 55)
- **Routing**: [Expo Router](https://docs.expo.dev/router/introduction/)
- **Styling**: Vanilla StyleSheet with HSL-based dynamic color tokens
- **Typography**: [Poppins](https://fonts.google.com/specimen/Poppins) (via Expo Google Fonts)
- **Icons**: [Ionicons](https://ionicons.com/) (via Expo Vector Icons)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)
- [Expo Go](https://expo.dev/go) app on your mobile device (for testing)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   pnpm install
   # OR
   npm install
   ```

3. Start the development server:
   ```bash
   npx expo start
   ```

4. Scan the QR code with your **Expo Go** app (Android) or **Camera app** (iOS) to run the project.
